# python port scanner
A simple python network port scanner created for cybersecurity practice.

# features
- scan TCP ports from 1 to 100
- detects open ports
- uses python socket programming
- scans localhost safely for practice

  ## technologies Used
  - python 3
  - socket library
  - TCP/IP networking

    ## how to run
    run the following command:
    python port_scanner.py
    ## example output
    scanning localhost. . .
    port 80 is open
    scan complete!
    ## purpose
    this project was created to practice python networking and basic cybersecurity concept.
    ## ethical use
    use this tool only on systems you own or have permission to test.
